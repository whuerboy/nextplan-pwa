# NextPlan PWA

一个纯本地、移动端优先的课程与计划管理工具。页面程序可以部署到任意静态/HTTPS 地址，但用户数据不会上传：计划存放在浏览器 IndexedDB，图片和视频也以 Blob 形式保存在当前设备。

## 已包含

- 首次打开自动写入当前 10 门课程（含老师、地点、周/双周规则）
- 固定的“下一项”卡片，正确保留正在进行或当天待完成的项目
- 月历 / 周历切换，每日安排按时间排序
- 计划增删改查、优先级、提醒提前量、重复规则、截止日期或永久重复
- 自定义注意事项卡片；每张卡片可组合文字、图片和视频
- JSON 完整备份与恢复（包含媒体附件）
- PWA manifest、App 图标和离线 Service Worker
- 支持 WebMCP 的计划读取、创建、修改和删除工具（浏览器支持时自动注册）

## 本机运行

```bash
npm install
npm run dev
```

打开终端显示的 Local 地址。构建检查：

```bash
npm run lint
npm run build
```

## iPhone 使用

PWA 在 iPhone 上安装需要 HTTPS 地址。将此前端发布到静态 HTTPS 托管后，用 Safari 打开，点“分享”→“添加到主屏幕”。发布的只是应用外壳；计划、课程、照片和视频仍只保存在每台设备的浏览器内。

提醒是纯本地的“运行期间提醒”：PWA 保持打开时会按提前量显示通知。iOS 若将网页完全挂起，纯本地网页无法像原生 App 一样保证后台定时通知；可靠的后台推送需要服务端 Web Push。

## 数据安全

- 删除计划后不会因刷新或重启重新写入。
- 清除 Safari 网站数据会删除本地计划。
- 换手机或清理浏览器前，应在“数据”页面导出完整备份。
